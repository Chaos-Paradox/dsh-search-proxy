# 0.5.1 发布说明草案

状态：版本准备，尚未发布。已发布的 [`v0.5.0`](https://github.com/Chaos-Paradox/dsh-search-proxy/releases/tag/v0.5.0)、原始标签、安装包与校验和保持不变；本批改动使用新版本 `0.5.1`，不替换旧资产。

## 本版改动

- 已记住的代理配置自动回填，协议、主机、端口和额外直连主机始终可查看和编辑。运行中修改后可点击「更新代理配置」，重新确认后保存；未修改时继续复用有效确认。
- 增加下载网络预检和网络故障引导，帮助识别 GitHub、codeload、PyPI 与 Python 软件包下载来源的连接问题。
- 按 profile 保留脱敏运行摘要，重启后可查看最近 100 条。两份日志文件各最多 128 KiB、合计最多 256 KiB，自动轮转；界面显示占用量并支持清除。
- 修复 Windows 超大日志恢复时未能截断文件的问题，对当前与轮转文件均验证截断、恢复追加及重新读取。
- 包版本、设置页版本及搜索请求 User-Agent 统一为 `0.5.1`，包含对应重建产物。

最低／推荐宿主继续为未打补丁的 DSH `0.2.1-alpha.2`。默认搜索路由、凭据隔离和默认关闭的付费备用行为保持原约定。从同名包 `0.5.0` 升级无需再次执行改名迁移；从旧包名升级仍按[迁移说明](rename.zh.md)操作。更新后完整重启 DSH 后端并刷新页面。

## 发布状态

本草案不表示 `v0.5.1` 标签或 Release 已存在。正式发布前应记录最终提交和 tarball SHA-256，完成当前构建的干净 tarball 安装、实际 Web 操作、托管生命周期与真实上游搜索验收，并核对对应三平台 CI。发布成功后再更新 README 的安装地址；当前 README 继续指向真实存在的 `v0.5.0`。
